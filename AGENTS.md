# AGENTS.md

## Назначение

Юзербот на Python и Telethon работает от имени Telegram-аккаунта. Он получает прайсы двух поставщиков, хранит версии локально, отправляет изменившиеся файлы в админ-бота и публикует отобранные новости Apple в отдельном канале.

## Прайсы поставщиков

| Поставщик | Источник и расписание | Кнопка загрузки в админ-боте |
| --- | --- | --- |
| aaa-store | Каждые 3 минуты с 11:00 до 21:00 по Москве отправляет партнёрскому боту «📊 Цены», нажимает «📊 Скачать Excel» и ищет документ не старше 5 минут среди последних 5 сообщений. | «📤 Загрузить aaa-store прайс» |
| «Сегодня там, завтра тут» | При запуске ищет первый документ с именем на `Apple` среди последних 20 сообщений канала. Затем обрабатывает новые документы с тем же префиксом по событиям Telegram, без ограничения по рабочим часам. | «📤 Загрузить прайс сегодня там, завтра тут» |

Оба сценария скачивают файл в `downloads/` и сравнивают его SHA-256 с последней версией поставщика. Последнюю версию определяют по дате и времени в имени. Любое отличие в байтах считается изменением, включая изменения метаданных Excel. При отсутствии предыдущей версии файл считается новым. При совпадении скачанный файл удаляется.

Новый файл сохраняется с меткой времени, например `Все товары_2026-11-20_12-30-00.xlsx`. Затем юзербот открывает панель админ-бота, нажимает кнопку поставщика и отправляет документ с подписью «Новый прайс». Подтверждение импорта со стороны админ-бота код не проверяет.

Версии старше трёх суток удаляются для соответствующего поставщика в конце обработки изменившегося файла. Если новых изменений нет или обработка прервалась исключением до очистки, старые версии могут храниться дольше. Сохранение происходит до отправки. Если отправка сорвалась, следующий файл с тем же содержимым будет принят за уже известную версию и отправка не повторится.

## Публикация новостей Apple

Юзербот слушает одиночные сообщения и альбомы в исходном канале. Он публикует записи, содержащие `#apple`, и пропускает записи, в которых одновременно есть `Реклама` и `ИНН ` (с пробелом). В тексте ссылка и упоминание Apple Inside заменяются на Mobiletime, хештег `#appleinside` удаляется. Фото отправляются вместе с текстом. При тексте длиннее 1024 символов фото и текст отправляются отдельно. Периодический опрос новостного канала есть в коде, но его запуск закомментирован.

## Настройки

| Где | Что задаётся |
| --- | --- |
| `.env` | `API_ID`, `API_HASH`, `PHONE_NUMBER` для Telegram-аккаунта. |
| `.env` | `TODAY_THERE_TOMORROW_HERE_CHANNEL_ID` для прайсов Apple. |
| `.env` | `NEWS_SOURCE_CHANNEL_ID` и `NEWS_DEST_CHANNEL_ID` для новостей. При поиске канала предусмотрены `NEWS_SOURCE_CHANNEL_LINK` и `NEWS_DEST_CHANNEL_LINK`. |
| `config.py` | Партнёрский и админ-боты, имя сессии, каталог и имена файлов, интервал опроса aaa-store и срок хранения. |
| `utils/time_utils.py` | Рабочие часы для aaa-store и часовой пояс `Europe/Moscow`. |

Каталог `downloads/` должен существовать и быть доступен для записи. Запускайте процесс из каталога проекта, чтобы относительные пути к загрузкам и сессии указывали на нужное место.

## Карта кода

- `main.py` запускает Telethon, делает первичную загрузку Apple-прайса, регистрирует обработчики новостей и запускает фоновый опрос aaa-store.
- `services/channel_service.py` регистрирует обработчик новых Apple-прайсов. `services/today_here_tomorrow_there_price_service.py` обслуживает этот источник, `services/aaa_store_price_service.py` обслуживает aaa-store.
- `services/bot_service.py` открывает админ-панель, ищет кнопки и отправляет файл. `utils/file_utils.py` отвечает за SHA-256, поиск версий и очистку.
- `services/apple_inside_channel_forwarder.py` фильтрует, редактирует и публикует новости.
- Инструкции по запуску на сервере находятся в [README.md](README.md).

## Мониторинг и алерты

На сервере настроен внешний мониторинг процесса. По наблюдению владельца, если остановить юзербот и оставить его выключенным, уведомление приходит в отдельный сервисный бот в течение пяти минут. Конфигурация мониторинга и сервисного бота находится вне репозитория.

`main.py` записывает Unix-метку в `/tmp/userbot_heartbeat` каждые две минуты. Запись подтверждает работу фоновой задачи Python. Она не проверяет связь с Telegram. После настройки обработчиков основной процесс ждёт `client.run_until_disconnected()`. При окончательном отключении он завершается. В лог попадает исключение Telethon или сообщение о закрытии соединения. Остановку обнаруживает внешний мониторинг процесса.

## Работа с проектом

- Для проверки изменения сначала проследите сценарий от `main.py` до обработчика поставщика или новости. Учитывайте, что загрузки и сессия используют пути относительно каталога запуска.
- Не публикуйте значения из `.env`, файлы Telegram-сессии, содержимое прайсов и токены сервисного бота. Запуск `main.py` с рабочей сессией может отправить сообщения и файлы в реальные Telegram-чаты.
